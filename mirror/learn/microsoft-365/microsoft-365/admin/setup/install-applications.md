# Install Microsoft 365 apps - Microsoft 365 admin | Microsoft Learn

After you set up Microsoft 365, install Microsoft 365 apps on your Mac, PC, or mobile devices.

## Watch: Install Microsoft 365 apps

This video shows how to install Microsoft 365 apps on a Windows device.

## Install Microsoft 365 apps in Windows

Microsoft 365 apps appear in your **Start** menu. If you don't see them, follow these steps to install Microsoft 365 apps in Windows:

1. Sign in to the [Microsoft 365 Apps](https://www.microsoft365.com/apps) by using your work account.
2. In the upper-right corner, select **Install apps**, and then select **Microsoft 365 apps**.
3. The **My account** page opens. Under **Office apps & devices**, select **Install Office**.
4. **OfficeSetup.exe** downloads to your **Downloads** folder. After the download finishes, open **OfficeSetup.exe** to start the installation.
5. When prompted with **Do you want to allow this app to make changes to your device?**, select **Yes** to start the installation.
6. The installation continues and might take several minutes to complete. When it completes, the **You're all set!** window displays. Select **Close**.
7. After installation, the apps appear in the **Start** menu and are ready to use.
