# Set up mobile devices for Microsoft 365 for Business - Microsoft 365 admin | Microsoft Learn

Learn how to set up mobile devices for Microsoft 365 for business on an iPhone or Android phone. After you complete these steps, your organization's security policies protect your work files created in Microsoft 365 apps, helping keep your business data secure.

The example in the tabs is for Microsoft Outlook, but it applies to any other Microsoft 365 apps you install.

## Install Microsoft 365 apps on your mobile device

Select the tab for your mobile device to see the steps to install Microsoft 365 apps and set up your work account:

# [iPhone](#tab/iPhone)
Watch a short video on how to set up Microsoft 365 productivity apps on iOS devices with Microsoft 365 for business.

Tip

If you found this video helpful, check out the [complete training series for small businesses and users new to Microsoft 365](../../business-video/).

1. Go to the **App Store**.

    [![Screenshot of the iPhone App Store.](../../media/886913de-76e5-4883-8ed0-4eb3ec06188f.png)](../../media/886913de-76e5-4883-8ed0-4eb3ec06188f.png#lightbox)
2. In the search field, enter **Microsoft Outlook** and then select **Get** to install Outlook.

    If you previously installed the app, a cloud icon appears instead of the **Get** button. Select the cloud icon to install Outlook.

    [![Screenshot of the App Store cloud icon used to reinstall Microsoft Outlook on iPhone.](../../media/665e1620-948a-4ab8-b914-dca49530142c.png)](../../media/665e1620-948a-4ab8-b914-dca49530142c.png#lightbox)
3. When the installation finishes, select the **Open** button to open Outlook, and then select **Get Started**.

    [![Screenshot of the Microsoft Outlook app open on iPhone with the Get Started button displayed.](../../media/005bedec-ae50-4d75-b3bb-e7cef9e2561c.png)](../../media/005bedec-ae50-4d75-b3bb-e7cef9e2561c.png#lightbox)
4. Enter your work email address on the **Add Email Account** screen and then select **Add Account**.
5. Enter your Microsoft 365 for business credentials and then select **Sign in**.

    [![Screenshot of Outlook sign in screen for work account on iPhone.](../../media/3cef1fb5-7bec-4d3d-8542-872b731ce19f.png)](../../media/3cef1fb5-7bec-4d3d-8542-872b731ce19f.png#lightbox)
6. If your organization is protecting files in apps, the following message appears in a dialog:

    **Your organization is now protecting the data in the app. You need to restart the app to continue.**

    [![Screenshot of Outlook app showing organization protection message on iPhone.](../../media/fb4c1c84-b1e9-42e1-8070-c13dcf79fb09.png)](../../media/fb4c1c84-b1e9-42e1-8070-c13dcf79fb09.png#lightbox)

    To restart Outlook, follow these steps:

    1. Select **OK** and close Outlook.
    2. Locate Outlook on the iPhone and then select it to reopen it.
    3. When prompted, enter a PIN and verify it.

        [![Screenshot of Outlook app prompting to set a PIN for organization data on iPhone.](../../media/64f2630b-3164-47a4-9dd6-ca0c29ed5fb3.png)](../../media/64f2630b-3164-47a4-9dd6-ca0c29ed5fb3.png#lightbox)
7. Outlook on your iPhone is ready to use.

# [Android](#tab/Android)
Watch a video about installing Outlook and Microsoft 365 on Android devices:

Tip

If you found this video helpful, check out the [complete training series for small businesses and users new to Microsoft 365](../../business-video/).

1. To begin setup on your Android phone, go to the **Play Store**.

    [![Screenshot of the Android home screen with the Google Play Store icon highlighted for mobile device setup.](../../media/93df88e7-c778-40e1-b35e-868ca6e97f6c.png)](../../media/93df88e7-c778-40e1-b35e-868ca6e97f6c.png#lightbox)
2. Enter **Microsoft Outlook** in the Google Play search box and select **Install**. Once Outlook finishes installing, select **Open**.

    [![Screenshot of Outlook app listing in Google Play Store with Open button on Android.](../../media/8b4c5937-8875-4b5a-a5b6-b8c6c9cd6240.png)](../../media/8b4c5937-8875-4b5a-a5b6-b8c6c9cd6240.png#lightbox)
3. In the Outlook app, select **Get Started**.
4. Add your Microsoft 365 for business email account and then select **Continue**.
5. Enter your organization credentials and then select **Sign in**.

    [![Screenshot of Outlook app sign in screen for organizational account on Android.](../../media/18f67c66-4bab-4b99-94bd-080839312e29.png)](../../media/18f67c66-4bab-4b99-94bd-080839312e29.png#lightbox)
6. In the dialog that states you must install the **Intune Company Portal** app, select **Go to store**.

    [![Screenshot of Outlook app with Go to store button for Intune Company Portal on Android.](../../media/a702d712-5622-45dd-a511-b1adaee63071.png)](../../media/a702d712-5622-45dd-a511-b1adaee63071.png#lightbox)
7. In the **Play Store**, select to install **Intune Company Portal**.

    [![Screenshot of Google Play Store with install button for Intune Company Portal app.](../../media/5e0408f2-3f37-44dd-80ed-13ca2ac6df0c.png)](../../media/5e0408f2-3f37-44dd-80ed-13ca2ac6df0c.png#lightbox)
8. Open Outlook again.
9. Enter and confirm a PIN.

    [![Screenshot of Outlook app prompting to set a PIN on Android.](../../media/edb91afb-f1ed-451a-bc6b-8ccba664e055.png)](../../media/edb91afb-f1ed-451a-bc6b-8ccba664e055.png#lightbox)
10. Your Outlook app is ready for use.
