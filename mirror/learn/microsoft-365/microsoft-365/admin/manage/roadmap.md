# Use the Microsoft AI at Work Roadmap - Microsoft 365 admin | Microsoft Learn

With dozens of apps and features, it can be challenging to keep up with what's new and what's coming. That's where the [Microsoft AI at Work Roadmap](https://www.microsoft.com/en-us/microsoft-365/roadmap), formerly known as Microsoft 365 Roadmap, comes in.

The roadmap is the central location for IT professionals, business decision makers, and anyone else who's interested, to see what's coming. It was created to help you plan, communicate changes, and take full advantage of your Microsoft 365 subscription.

## Search features

Find features by typing in a roadmap ID, a keyword from the description, or a tag into the search bar. The best way to find a specific feature is to search by its unique roadmap ID. You can also search by a keyword such as "SMTP domain" that might be in the description. Use filters to narrow down your search. Sort roadmap items by preview availability or rollout date.

### Filter features

The following table describes the filters available on the Microsoft AI at Work Roadmap.

| Filter | Description |
| --- | --- |
| **Products** | Search and select from the list of Microsoft 365 products, sorted alphabetically. If multiple products are selected, results show all features tagged with any of the selected products. |
| **Status** | Each feature is assigned a status which is updated over the lifecycle of the feature. The status tracks a feature's progression toward and through its production release phase, shown on the roadmap as **General Availability**. Once a feature begins deploying to production, its status moves from **In development** to **Rolling Out**, and then to **Launched** when deployment completes.Filter by the following statuses:- **In development**: The feature is currently in development and testing, and might be available to some customers who have elected to participate in a preview program.- **Rolling out**: The feature is beginning to roll out to the first applicable customers and isn't available yet to all applicable customers.- **Launched**: The feature is available to all applicable customers. |
| **Release phase** | This filter includes [release options for Microsoft 365 services](configure-release-options) and [update channels for Microsoft 365 Apps](/en-us/microsoft-365-apps/updates/overview-update-channels).For features available as a public preview, the item is tagged with the **Preview** release phase and displays a **Preview Available** date. However, the roadmap status remains **In Development**, as preview features are still being validated and might change before they are released to production.For production feature availability, the **Rollout Start** date indicates when the feature begins rolling out broadly to customers in Current Channel and General Availability. |
| **Platform** | Where applicable, features are tagged with one or more platforms. |
| **Cloud instance** | Use this filter to select your specific cloud environment.- **GCC, GCC High, or DoD**: Government specific dedicated cloud instances that meet different compliance levels. For more information about each service description, see [Office 365 GCC](/en-us/office365/servicedescriptions/office-365-platform-service-description/office-365-us-government/gcc) and [Office 365 GCC High and DoD](/en-us/office365/servicedescriptions/office-365-platform-service-description/office-365-us-government/gcc-high-and-dod).- **Worldwide (Standard Multi-Tenant)**: This is the standard cloud, not restricted to a certain country/region or government. |
| **New or updated** | View features that were added or modified within the last week or the last month. |

## Understand roadmap feature cards

Features are displayed on expandable feature cards using the plus symbol.

Each feature card displays the feature title, status, product, description, tags, the date it was added to the roadmap, and the date it was last modified. Expand the feature card to see details, including the roadmap ID, description, cloud instance, and more.

## Share feature information

### Share via email

Within a specific feature card, select the envelope icon to share a link to a specific feature via email. Your default mail app opens with a link to the feature in the body of a new email.

### Subscribe to an RSS feed

You can subscribe to Microsoft AI at Work Roadmap RSS updates with Microsoft Outlook or another RSS reader. To receive updates for all features on the Microsoft AI at Work Roadmap, select the RSS icon located above the roadmap filters. If you want to follow only specific features, select the RSS icon on an individual feature.

For more information about adding an RSS feed to Outlook, see [Subscribe to an RSS Feed](https://support.microsoft.com/outlook/subscribe-to-an-rss-feed).

### Send direct link

To share a link to the entire Microsoft AI at Work page with your current filter selections, copy the URL in your browser and share. The URL has your filter selections encoded.

To share a specific feature, expand the feature card and select the link icon under Share to copy the direct link to that feature.

## Get AI-powered change insights

For Microsoft AI at Work Roadmap and Azure Updates information, connect to **Microsoft Release Communications MCP Server** to enable AI agents to answer questions about upcoming features, rollout timelines, and product changes. For more information, see [Microsoft Release Communications MCP Server](mrc-mcp).

## Download roadmap feature information

Select the download icon above the roadmap filters to download all or only the filtered roadmap feature information displayed in a CSV file format.

## Give feedback

To provide feedback about the site or existing roadmap items, use the feedback button. If your feedback is for a specific feature, include the feature ID in your comment.
