# Set up Microsoft 365 for Google Workspace migration - Microsoft 365 admin | Microsoft Learn

This article helps you get started with Google Workspace migration after signing up for Microsoft 365 Business Premium.

## Open the Google Workspace migration tools

1. Sign in to the [Microsoft 365 admin center](https://admin.microsoft.com).
2. Select **Setup** &gt; **Migration resources**.
3. Under **Self-service migration and import tools**, select **Explore migration & imports tools**.
4. Select **Google Workspace** to open its migration page.

## Prepare your organization

Before starting migration:

1. [Add and verify your business domain](add-google-domain).
2. For email migration, complete the [email migration prerequisites](migrate-email#prerequisites-for-automated-batch-migration-from-google-workspace).
3. [Set up device protection](../security-and-compliance/m365bp-devices-enrollment) when users' accounts and licenses are ready.

Continue with [email migration](migrate-email) or [Google Drive migration](migrate-files-migration-manager).
