# Viva Insights Activity Report - Microsoft 365 admin | Microsoft Learn

Use the Viva Insights activity report to measure Viva Insights adoption in your organization.

In this article, you can:

- Open the report in the Microsoft 365 admin center.
- Read active user trends for the last 7, 30, 90, or 180 days.
- Understand what actions count as an active user.

To increase adoption after reviewing report data, use the [Viva Insights Deployment guide](/en-us/viva/insights/personal/setup/deployment-guide).

For general information about usage reports in the Microsoft 365 admin center, and to see a list of all available reports, see [Microsoft 365 admin center usage reports overview](activity-reports).

## View the Viva Insights activity report in the Microsoft 365 admin center

For information about the roles needed to view usage reports, see "Before you begin" in [Microsoft 365 admin center usage reports overview](activity-reports#before-you-begin)

1. Go to the [Microsoft 365 admin center](https://go.microsoft.com/fwlink/p/?linkid=2024339).
2. In the navigation menu, select **Reports**. If you don't see **Reports**, select **Show all**, and then select **Reports**.
3. Select [Usage](https://go.microsoft.com/fwlink/p/?linkid=2074756).
4. On the **Usage** page, under **Reports**, select **Viva Insights activity**.

## Interpret the Viva Insights activity report

You can view your user's Viva Insights activity by looking at the **Active users chart**. The report displays trends over the last 7, 30, 90, or 180 days.

[![Screenshot of the Viva Insights activity report.](../../media/viva-insights-chart.png)](../../media/viva-insights-chart.png#lightbox)

**Active users** are users who engage with at least one Viva Insights feature that day. Engagement includes the following actions:

- Spending more than 20 seconds on a Viva Insights email.
- Clicking or taking an action on an Insights surface.
- Visiting Viva Insights in Teams, the Outlook add-in, or web dashboards.
