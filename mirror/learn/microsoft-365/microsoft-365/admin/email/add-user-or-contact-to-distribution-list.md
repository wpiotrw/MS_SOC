# Add Users or Contacts to Microsoft 365 Distribution List Groups - Microsoft 365 admin | Microsoft Learn

As an admin, you can add users or contacts to a Microsoft 365 distribution list group so they receive group email. Use these steps to quickly manage members in the admin center. See [Create distribution list groups in Microsoft 365](../setup/create-distribution-lists).

## Steps to add users or contacts to a Microsoft 365 distribution list group

To add users or contacts to a Microsoft 365 distribution list group, follow these steps:

1. Sign in to the [Microsoft 365 admin center](https://admin.cloud.microsoft/).
2. From the left navigation bar, select **… Show all**, and then select **Teams and groups**.
3. Under **Teams and groups**, select [**Active teams and groups**](https://admin.cloud.microsoft/?#/groups).
4. In the **Active teams and groups** page, select the **Distribution list** tab.
5. In the list of distribution list groups, select the name of the distribution list group you want to add users or contacts to.
6. In the distribution list group details pane that opens, select the **Members** tab.
7. Under the **Members** section, select **View all and manage members**.
8. In the **Members** pane, select **+ Add members**.
9. In the **Add members** pane, find the users or contacts you want to add to the distribution list group and then select them. You can search for a user or contact by entering their name in the **Search for a member** search box.
10. Once all of the users or contacts you want to add are selected, select **Add**.
11. Close the **Members** pane.

## Steps to remove users or contacts from a Microsoft 365 distribution list group

To remove users or contacts from a Microsoft 365 distribution list group, follow these steps:

1. Sign in to the [Microsoft 365 admin center](https://admin.cloud.microsoft/).
2. From the left navigation bar, select **… Show all**, and then select **Teams and groups**.
3. Under **Teams and groups**, select [**Active teams and groups**](https://admin.cloud.microsoft/?#/groups).
4. In the **Active teams and groups** page, select the **Distribution list** tab.
5. In the list of distribution list groups, select the name of the distribution list group you want to remove users or contacts from.
6. In the distribution list group details pane that opens, select the **Members** tab.
7. Under the **Members** section, select **View all and manage members**.
8. In the **Members** pane, select the users or contacts from the list of members that you want to remove and then select **Remove members**. You can search for a user or contact by entering their name in the **Search member list** search box.
9. Close the **Members** pane.
