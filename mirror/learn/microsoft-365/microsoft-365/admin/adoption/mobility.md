# Microsoft Adoption Score - Mobility - Microsoft 365 admin | Microsoft Learn

Adoption Score provides insights into your organization's digital transformation journey through its use of Microsoft 365 and the technology experiences that support it. Your organization's score reflects technology experience measurements and can be compared to benchmarks from organizations similar to yours. To learn more, check out the [Adoption Score overview](adoption-score) and read [Microsoft's Privacy Statement](https://privacy.microsoft.com/privacystatement).

## Prerequisites

To get started with Mobility insights, users in your organization need to be licensed for:

- Microsoft Teams
- Exchange Online
- Word
- Excel
- PowerPoint
- OneNote

For more information, see [assign licenses to users](../manage/assign-licenses-to-users).

When users are active in these products at least once in the last 28 days, you start to see the insights.

## Why your organization's mobility score matters

A fundamental pillar of organizational productivity is how well users are able to work flexibly from wherever they are. With Microsoft 365, users can stay connected with Outlook, Microsoft Teams, and Viva Engage. Users can also seamlessly collaborate on content by using Word, Excel, PowerPoint, and OneNote from any location, and platforms.

## How the mobility score is calculated

Primary insight in the experience that contains the key metrics for this category in your organization is provided. Then a scoring framework is used for these metrics to calculate your organization's score.

### Primary insight

Microsoft 365 lets users work flexibly across apps, including Microsoft Outlook, Word, Excel, PowerPoint, OneNote, Microsoft Teams, Viva Engage, and Skype for Business. Users can also work from anywhere by using a seamless experience across desktop, web, and mobile platforms. The primary insight looks at the products that are enabled for users in your organization - and how many of these users are active on at least two platforms.

[![Chart showing primary insight for Mobility - users experiences Adoption Score.](../../media/primary-mobility.png)](../../media/primary-mobility.png#lightbox)

1. **Header**: Shows the percentage of users in your org who:

    - Have access to any of Microsoft 365 Apps.
    - Are active on at least one of these applications on more than one platform.
2. **Body**: Provides more information on how the use of these applications on multiple platforms can promote efficiency and satisfaction.
3. **Visualization (current state)**: Shows how many users use more than one platform across desktop, mobile, and web for at least one Microsoft 365 as follows:

    - **Horizontal bar** where the blue (colored) portion represents the percentage expressed in the header.
    - **The fraction** on the bar highlights the (numerator/denominator) used for calculating the percentage in the header.

        - **Numerator**: The number of users in your org using any application within Microsoft Outlook, Word, Excel, PowerPoint, OneNote and Microsoft Teams, Viva Engage, and Skype on more than one platform from desktop, web, and mobile in the last 28 days.
        - **Denominator**: The number of users licensed for Microsoft 365 Apps, Exchange, Viva Engage, Microsoft Teams, or Skype for at least one of the last 28 days.
    - The **peer benchmark** value for the key metric is also shown as a percentage.
4. **View Mobility resources**: To view help content, select this link.

#### Trend visualization of the primary insight

[![Chart showing number of users who use more than one platform vs. time.](../../media/mobility-primary.png)](../../media/mobility-primary.png#lightbox)

This chart shows the trend-line, where the numerator is the number of users who used apps over the last 180 days. Each data point on the line chart is an aggregate of activity for the last 28 days. Each data point provides a count of all users in your org using an application across at least two platforms in the last 28 days for each date on the x-axis.

### Scoring framework

The mobility score for your organization measures at an organization (aggregate) level whether users are using Microsoft 365 Apps - Outlook, Teams, Word, Excel, PowerPoint, OneNote, Viva Engage, and Skype - across the different platforms - desktop, web, and mobile.

The scores aren't provided at the individual user level.

## Explore how your org works across platforms and locations

We also provide you with information that helps you gain visibility into how users in your organization work across platforms. These additional metrics don't directly contribute to your Adoption Score, but help you create an action plan as part of your digital transformation.

### Use of Outlook across platforms

[![Chart that shows how many users are using Outlook on multiple platforms.](../../media/outlook-across-platforms.png)](../../media/outlook-across-platforms.png#lightbox)

1. **Header**: Shows the percentage of users active on Outlook who are using Outlook on multiple platforms.
2. **Body**: Provides information about the value of using Outlook on mobile devices to help stay connected from anywhere on email.
3. **Visualization**: Shows the percentage of users who are active on Outlook and are using either one or more than one platform:

    - **Multiple platforms**:

        - **Numerator**: The number of users who used Outlook on at least two platforms from desktop, mobile, or web in the last 28 days.
        - **Denominator**: The number of users who used Outlook at least once in the last 28 days.
    - **Desktop only**:

        - **Numerator**: The number of users who used Outlook on only a desktop platform in the last 28 days.
        - **Denominator**: The number of users who used Outlook at least once in the last 28 days
    - **Web only**:

        - **Numerator**: The number of users who used Outlook on only a web platform in the last 28 days.
        - **Denominator**: The number of users who used Outlook at least once in the last 28 days.
    - **Mobile only**:

        - **Numerator**: Number of users who used Outlook on only a mobile platform in the last 28 days.
        - **Denominator**: Number of users who used Outlook at least once in the last 28 days.

### Use of Teams across platforms

[![Chart that shows how many users are using Teams on more than one or single platform.](../../media/teams-across-platforms.png)](../../media/teams-across-platforms.png#lightbox)

1. **Header**: Shows what percentage of users who are active on Microsoft Teams are using it on multiple platforms.
2. **Body**: Provides information about the value of using Teams on mobile devices to help users stay up to date on messages while working from any location.
3. **Visualization**: Shows the percentage of users active on Microsoft Teams who are using it on either a single platform, or multiple ones:

    - **Multiple platforms**:

        - **Numerator**: The number of users who used Teams in the last 28 days on 2 or more of the following platforms: desktop, mobile, or web.
        - **Denominator**: The number of users who used Microsoft Teams at least once in the last 28 days.
    - **Desktop only**:

        - **Numerator**: The number of users who used Microsoft Teams only on a desktop platform in the last 28 days
        - **Denominator**: The number of users who used Teams at least once in the last 28 days
    - **Web only**:

        - **Numerator**: The number of users who used Microsoft Teams only on a web platform in the last 28 days
        - **Denominator**: The number of users who used Microsoft Teams at least once in the last 28 days
    - **Mobile only**:

        - **Numerator**: The number of users who used Microsoft Teams only on a mobile platform in the last 28 days
        - **Denominator**: The number of users who used Teams at least once in the last 28 days

### Use of Microsoft 365 productivity apps across platforms

[![Chart that shows number of users who use Microsoft 365 productivity apps on multiple or single platforms.](../../media/microsoft-365-apps-platforms.png)](../../media/microsoft-365-apps-platforms.png#lightbox)

1. **Header**: Shows the percentage of users active on Microsoft 365 Apps (Word, Excel, PowerPoint, and OneNote) on multiple platforms.
2. **Body**: Provides information about the value of providing users in your organization the flexibility to access their files from anywhere.
3. **Visualization**: The grouped vertical is meant to represent the number of users who are using each of the apps considered - Word, Excel, PowerPoint, and OneNote - across single or multiple platforms. For each of these applications, bars represent the following information:

    - **Multiple platforms**: The number of users active on an app across at least two platforms in the last 28 days.
    - **Desktop only**: The number of users active on app on only the desktop platform in the last 28 days.
    - **Web only**: The number of users active on app on only the web platform in the last 28 days.
    - **Mobile only**: The number of users active on app on only mobile platform in the last 28 days.

## View mobility trends over time

For each of the insights in this article, you can see how the metrics trend over time by selecting an option from the **Data View** dropdown menu.

[![Screenshot of trends over time.](../../media/trends-over-time.png)](../../media/trends-over-time.png#lightbox)

After you select an option, the charts in the report will update to show a trend over time rather than a snapshot of the past month.
