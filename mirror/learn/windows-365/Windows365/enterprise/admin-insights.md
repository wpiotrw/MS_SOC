# Admin Insights for Windows 365 | Microsoft Learn

Important

Windows 365 Frontline is now **Windows 365 Flex**. The product name in the Microsoft Intune admin center is being updated and may still appear as **Frontline** in some places. This article reflects those existing references where updates are still in progress. For more information about the rebrand, see [Expanding access to Windows 365](https://techcommunity.microsoft.com/blog/windows-itpro-blog/windows-365-and-azure-virtual-desktop-expanding-access/4515931).

Admin Insights for Windows 365 gives IT administrators a prioritized set of items to review—such as issues that need attention and opportunities to optimize your Cloud PC environment—directly in the Windows 365 experience in the Microsoft Intune admin center.

Admin Insights is **service-driven**: items are generated by the Windows 365 service and aren't configured through customer-defined thresholds or alert rules.

## How Admin Insights is different from Alerts

Windows 365 **Alerts** are rule-based and customizable (conditions, severity, enable/disable, notifications). **Admin Insights** surfaces a prioritized list of service-identified items in context within Intune, helping IT administrators quickly decide what to investigate next.

For alert-based notifications and rule configuration, see [Alerts in Windows 365](alerts).

## Requirements

To see Admin Insights, you must meet the following requirements:

- Windows 365 Enterprise or Windows 365 Flex licensing in your tenant.
- Read permissions for Windows 365 resources (typically provided through Cloud PC Reader, Cloud PC Administrator, or Windows 365 Administrator roles).

## View Admin Insights

Admin Insights is available on the **Cloud PC Overview** page and the **Connection health** tab of the **Monitor Cloud PCs** page in the Microsoft Intune admin center.

Sign in to the [Microsoft Intune admin center](https://go.microsoft.com/fwlink/?linkid=2109431) and go to:

- **Devices &gt; Manage Windows 365 Cloud PCs &gt; Cloud PC Overview**
- **Devices &gt; Manage Windows 365 Cloud PCs &gt; Monitor Cloud PCs &gt; Connection health** tab

![Screenshot that shows admin insights on the cloud pc overview page.](media/admin-insights/screenshot-that-shows-admin-insights-on-the-cloud-pc-overview-page.png)

![Screenshot that shows admin insights in monitor cloud pcs.](media/admin-insights/image-showing-admin-insights-in-monitor-clouds-pcs.png)

Admin Insights appears as a section on the Cloud PC Overview page and the Connection health tab of the Monitor Cloud PCs page, displaying relevant items for your tenant when the page loads.

### Insight categories

Admin Insights includes items related to:

- Cloud PC health and connectivity
- Provisioning and lifecycle
- Performance and utilization
- Windows 365 Flex concurrency
- Service health

## Understand what you're seeing

### When insight cards appear

Insight cards are displayed when predefined thresholds are met. When thresholds aren’t met—or the signed-in administrator has dismissed all available cards—no cards are displayed and a **You’re all caught up** message appears.

These cards are dynamically generated based on activity across your Cloud PC environment. Up to 15 insight cards can be displayed, covering general health and outlier conditions.

### Severity and prioritization

Admin Insights categorizes items by severity (for example, Error, Warning, or Recommendation) and returns them as a ranked list.

### Linked actions and reports

Admin Insights helps you jump to underlying reports where applicable. If you have access to Copilot in Intune, you can invoke Copilot to provide more context and guidance related to the insight.

## Dismiss an insight

You can dismiss an insight for 24 hours. The dismissal applies only to the signed-in administrator. Other administrators in the same tenant continue to see the insight unless they dismiss it independently.

## Troubleshooting

If Admin Insights does not appear as expected:

1. Confirm you're on the **Cloud PC Overview** page or the **Connection health** tab on the **Monitor Cloud PCs** page in Intune.
2. Refresh the page to load the latest view for that session.
3. Validate your Windows 365 and Intune permissions if you can't access Windows 365 pages.
4. If the issue persists, open a support request and include the approximate time you tested and what you expected to see.

## Known limitations

- Admin Insights cards show tenant-wide aggregate data and don’t currently apply Intune scope tags. When administrators open a linked report, scope-tag behavior is determined by that report.
- Admin Insights cards can't be permanently dismissed.
- Admin Insights cards can't be configured with custom thresholds.
