# Microsoft Purview setup guides | Microsoft Learn

Microsoft Purview setup guides offer a guided experience for planning and deploying data security and compliance solutions in your organization.

These guides organize the basic solution configuration steps and help point you directly to primary guidance for these steps in Microsoft Purview documentation. By using the authenticated experience in the admin center guides, you can also use automation for some solution configuration steps to help you quickly get started with your solution deployment.

Setup guides in the admin center require authentication to Microsoft Purview as an administrator or other role with access to the [Microsoft 365 admin center](https://go.microsoft.com/fwlink/?linkid=2224913). However, anyone can access the guides in the [Microsoft 365 Setup portal](https://go.microsoft.com/fwlink/?linkid=2220880).

## Setup guides

| Guide:[Setup Portal](https://go.microsoft.com/fwlink/?linkid=2220880) | Guide:[Admin Center](https://go.microsoft.com/fwlink/?linkid=2224913) | Description |
| --- | --- | --- |
| [Audit setup guide](https://go.microsoft.com/fwlink/?linkid=2223153) | [Audit setup guide](https://go.microsoft.com/fwlink/?linkid=2224816) | **Microsoft Purview Auditing Solutions setup guide** provides guidance to enable and configure auditing in Microsoft 365. The guide covers verifying licensing, assigning permissions, enabling Audit (Premium) events, creating audit retention policies, and using the unified audit log to search and review user and admin activities for investigations. |
| [Manage data exfiltration with Purview](https://go.microsoft.com/fwlink/?linkid=2326849) | [Manage data exfiltration with Purview](https://go.microsoft.com/fwlink/?linkid=2326756) | The **Manage data exfiltration with Microsoft Purview setup guide** provides steps to configure Insider Risk Management policies, link Data Loss Prevention alerts, and enable auditing and labeling features to prevent unauthorized data transfers. The guide highlights built-in tools that streamline permission setup for Microsoft 365 groups, reducing manual steps and improving configuration efficiency. |
| [Secure by default with Purview](https://go.microsoft.com/fwlink/?linkid=2310737) | [Secure by default with Purview](https://go.microsoft.com/fwlink/?linkid=2310839) | The **Secure by default with Microsoft Purview setup guide** provides guidance to enable default security configurations and apply encryption and sensitivity labels automatically across Microsoft 365. The guide covers publishing default labels, configuring auto-labeling for Office apps, setting contextual defaults for SharePoint and Microsoft Teams, and enabling built-in labeling for Office for the web to achieve broad coverage with minimal user interaction. |
