# Consent to use use pay-as-you-go capabilities | Microsoft Learn

Applies to:

- Existing Azure Purview customers who are using the classic data governance pricing model.
- Microsoft Purview customers using Data Security pay-as-you-go features in free public preview.

Important

You can only use this procedure if your organization is in one of the above categories.

This feature is in preview.

## Consent to use pay-as-you-go capabilities

If your organization is in one of the above categories, you must give your consent to switch from your current billing model to the pay-as-you-go model.

If you aren't familiar with the pay-as-you-go model see, [Learn about Microsoft Purview billing models](purview-billing-models#learn-about-microsoft-purview-billing-models).

## Prerequisites for pay-as-you-go

To consent to changing to the pay-as-you-go model, you must have these prerequisites.

### Roles and permissions to consent to the pay-as-you-go pricing structure

Only an account in the Global Administrator role can provide consent to switch to the pay-as-you-go model.

## Consent experience

Microsoft Purview has a single unified consent experience that applies to all pay-as-you-go apps and capabilities. Your consent applies to all current and future pay-as-you-go features, as they transition from free to paid public preview.

Note

Although the consent experience is common for all apps and capabilities, certain apps may not be available in all regions. For instance, data governance is currently available in specific regions. For more information on region availability, see [Supported regions for Microsoft Purview Data Governance](unified-catalog-regions).

1. Open the [Microsoft Purview portal](https://purview.microsoft.com) &gt; **Settings** &gt; **Account overview** in the new Microsoft Purview portal.
2. Select **Review Consent** and switch to the pay-as-you-go model.
3. Microsoft Purview Unified Catalog app customers can learn more [here](data-governance-billing).
4. A confirmation is displayed that you've successfully switched to the new business model.
