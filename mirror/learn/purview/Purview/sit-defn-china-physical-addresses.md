# China physical addresses entity definition | Microsoft Learn

This unbundled named entity detects patterns related to physical address from China. It is also included in the [All Physical Addresses](sit-defn-all-physical-addresses) bundled named entity SIT.

## Confidence level

Medium

## Keyword Highlighting

Supported

When keyword highlighting is supported in the contextual summary for a sensitive information type or a trainable classifier, in the **Contextual Summary** view of activity explorer, the keywords in a document that were matched to a policy are highlighted.
