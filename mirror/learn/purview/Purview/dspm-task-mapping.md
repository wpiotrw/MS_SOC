# Map tasks that you used to do in Microsoft Purview Data Security Posture Management (DSPM) for AI, or in Microsoft Purview Data Security Posture Management (DSPM), to the new version of DSPM | Microsoft Learn

> 
> *[Microsoft Purview service description](/en-us/office365/servicedescriptions/microsoft-365-service-descriptions/microsoft-365-tenantlevel-services-licensing-guidance/microsoft-purview-service-description)*

Note

This documentation is for the **current** version of Data Security Posture Management that expands coverage to more data sources, introduces guided workflows for proactive risk management, and streamlines data security operations so you can more confidently adopt AI across your digital estate.

Most new features will be added to this version only but you can still access the previous versions and their documentation:

- [DSPM for AI (classic)](dspm-for-ai)
- [DSPM (classic)](data-security-posture-management)

Microsoft Purview Data Security Posture Management (DSPM) for AI, and Microsoft Purview Data Security Posture Management (DSPM), have converged into a single, central solution. This unified version helps you more easily discover, protect, and investigate your data by using security and governance solutions from Microsoft Purview.

Many of tasks that you used to do in previous versions are now embedded in the context of data security objectives, although they can still be accessed independently. Data security objectives are new in Data Security Posture Management, and you find them front and center with **DSPM** &gt; **Objectives**.

Data security objectives focus on the business outcomes you want to achieve. Choose an objective and we recommend a combination of Microsoft Purview solutions and specific actions to help you meet that outcome, with as few clicks as possible to achieve it. For more information, see [Objectives and outcomes](data-security-posture-management-learn-about#data-security-objectives).

To help you navigate the new Data Security Posture Management for the tasks you used to do in previous versions, use the following tables.

## Tasks that you did in DSPM for AI

| Task in DSPM for AI | Navigation for the new Data Security Posture Management |
| --- | --- |
| Setup tasks that include auditing and extending your insights for data discovery | 1. When you first open **DSPM** &gt; **Getting Started** 2. **DSPM** &gt; **Actions** &gt; **Setup tasks** |
| Recommendations for AI apps | **DSPM** &gt; **Actions** &gt; **Remediation actions** |
| Microsoft 365 Copilot overview page | **DSPM** &gt; **Reports** &gt; **Microsoft 365 Copilot** |
| Reports to see results of one-click policies | **DSPM** &gt; **Reports** |
| Policies for AI apps | **DSPM** &gt; **Reports** &gt; **Policies with AI workloads** |
| Apps and agents | **DSPM** &gt; **Discover** &gt; **Apps and agents** See also: **AI observability** that includes more information and support for Agent 365 |
| Activity explorer | **DSPM** &gt; **Discover** &gt; **Activity explorer** &gt; **AI activities** tab |
| Data risk assessments | **DSPM** &gt; **Discover** &gt; **Data risk assessments** |

## Tasks that you did in DSPM

| Task in DSPM | Navigation for the new Data Security Posture Management |
| --- | --- |
| Opt in to analytics processing and scanning | When you first open **DSPM** &gt; **Getting Started** |
| Recommendations | **DSPM** &gt; **Actions** &gt; **Remediation actions** |
| Reports and trends | **DSPM** &gt; **Reports** See also: **DSPM** &gt; **Posture** |
| Security Copilot promptbooks | **DSPM** &gt; **Posture** Security Copilot promptbooks are surfaced contextually within objectives and their workflows |

## Get started with the new Data Security Posture Management

[Sign in to the Microsoft Purview portal](https://purview.microsoft.com) &gt; **Solutions** &gt; **DSPM**.

Use an account with one of the following roles or role groups:

- **Microsoft Entra Compliance Administrator** role
- **Microsoft Entra Global Administrator** role
- **Microsoft Purview Compliance Administrator** role group

Note

Some activities require additional roles. For more information, see [Permissions for Data Security Posture Management](data-security-posture-management-permissions).

For more information about this latest version of Data Security Posture Management, with a guided walkthrough, see [Learn about Data Security Posture Management](data-security-posture-management-learn-about).
