# Azure machine configuration agent release notes overview - Azure Machine Configuration | Microsoft Learn

The machine configuration agent receives improvements on an ongoing basis. To stay up to date with the most recent developments by platform, see the following articles:

- [Azure machine configuration agent for Windows release notes](windows) (`Microsoft.GuestConfiguration.ConfigurationforWindows`)
- [Azure machine configuration agent for Linux release notes](linux) (`Microsoft.GuestConfiguration.ConfigurationforLinux`)

Each article provides you with information about:

- The latest releases
- Known issues
- Bug fixes

For information on release notes for the connected machine agent, see [What's new with the connected machine agent](/en-us/azure/azure-arc/servers/agent-release-notes).
