# Savings plan cancellation policies - Microsoft Cost Management | Microsoft Learn

All savings plan purchases are final. After you buy a savings plan, you can't cancel it or exchange it for a reservation.

## Savings plans and reservations

Although you can't cancel or exchange a savings plan, you can trade in eligible reservations for a new savings plan. For more information about reservation trade-ins, see [Self-service trade-in for savings plans](reservation-trade-in).
