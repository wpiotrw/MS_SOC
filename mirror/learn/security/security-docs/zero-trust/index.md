# Zero Trust Guidance Center

Zero Trust security “assumes breach,” “never trusts,” and “always verifies.” The Zero Trust Guidance Center helps you adopt security, deliver secure business outcomes, and protect technology pillars such as identity, devices, and data across your organization.

## Secure technology pillars across the business

Implement Zero Trust security to achieve business outcomes and protect technology pillars.

![](/en-us/security/media/hubpage/security-icons/microsoft-entra.svg)[Identity](/en-us/security/zero-trust/deploy/identity)
Secure identities with strong authentication, conditional access, and comprehensive identity protection.

![](/en-us/security/media/hubpage/security-icons/microsoft-intune.svg)[Endpoints](/en-us/security/zero-trust/deploy/endpoints)
Protect devices with comprehensive endpoint security and compliance policies.

![](/en-us/security/media/hubpage/app-type-desktop.svg)[Applications](/en-us/security/zero-trust/deploy/applications)
Secure applications with modern authentication and API protection.

![](/en-us/security/media/hubpage/security-icons/microsoft-purview.svg)[Data](/en-us/security/zero-trust/deploy/data)
Protect sensitive information with classification, encryption, and data loss prevention.

![](/en-us/security/media/hubpage/security-icons/microsoft-defender.svg)[Infrastructure](/en-us/security/zero-trust/deploy/infrastructure)
Secure infrastructure with workload protection and configuration management.

![](/en-us/security/media/hubpage/azure-networking.svg)[Networks](/en-us/security/zero-trust/deploy/networks)
Implement network security with segmentation, encryption, and threat protection.

![](/en-us/security/media/hubpage/security-icons/microsoft-sentinel.svg)[Visibility, automation, and orchestration](/en-us/security/zero-trust/deploy/visibility-automation-orchestration)
Enable comprehensive visibility and automated threat response across your environment.

![](/en-us/security/media/hubpage/github.png)[Developer guidance](/en-us/security/zero-trust/develop/overview)
Embed Zero Trust principles into your development workflow and applications.
