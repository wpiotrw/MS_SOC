# Non-Microsoft plugins for Microsoft Security Copilot | Microsoft Learn

Important

Some information in this article relates to a prereleased product that may be substantially modified before it's commercially released. Microsoft makes no warranties, express or implied, with respect to the information provided here.

Microsoft Security Copilot supports many plugins, including Microsoft and non-Microsoft plugins. This article describes several examples of non-Microsoft plugins you can use with Security Copilot. Each plugin has a specific function. Some, but not all, require authentication to configure integration with Security Copilot.

Note

Microsoft will be processing and storing data from these plugins according to our [Privacy and Data](privacy-data-security) policies.

## Find and use other plugins

1. Sign in to [Microsoft Security Copilot](https://securitycopilot.microsoft.com/).
2. Access **Manage plugins** by selecting the **Sources** button from the prompt bar.
3. Scroll down to **Non-Microsoft**, and select the plugin you want to use. Here are some examples:

    - [AbuseIPDB](plugin-abuseipdb)
    - [Aviatrix](plugin-aviatrix)
    - [Censys](plugin-censys)
    - [CheckPhish](plugin-checkphish)

    - [Cyware Respond](plugin-cyware)
