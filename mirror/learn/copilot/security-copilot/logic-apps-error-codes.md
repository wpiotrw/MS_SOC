# Microsoft Security Copilot Logic Apps Connector error codes | Microsoft Learn

Learn about the error codes that you might encounter when using the Security Copilot Logic Apps Connector.

| Code | Errors | Details |
| --- | --- | --- |
| **403** | Forbidden | - You might not have the right permissions assigned to you. For more information, see [Understand authentication in Microsoft Security Copilot](authentication). |
| **429** | Too many requests | - Ensure you have sufficient capacity. For more information, see [Manage usage of security compute units in Security Copilot](manage-usage). |
