# Connectors overview Microsoft Security Copilot (Preview) | Microsoft Learn

The connectors in Security Copilot are a wrapper around the API that allows the developers and users to call out to the Microsoft Security Copilot platform to perform specialized tasks.

For more information, see [Microsoft Security Copilot connector](/en-us/connectors/securitycopilot).

## Creating connectors

The following connectors are currently supported:

- Logic Apps connector
- Copilot Studio connector
