# Microsoft Entra External ID agent toolkit overview - Microsoft Entra External ID | Microsoft Learn

The Microsoft Entra External ID agent toolkit is a collection of skills for AI coding agents that help you work on Microsoft Entra External ID apps. Choose a task-specific skill to help onboard an app or migrate an existing native authentication implementation.

**Applies to**: ![Green circle with a white check mark symbol that indicates the following content applies to external tenants.](../media/common/applies-to-yes.png) External tenants ([learn more](/en-us/entra/external-id/tenant-configurations))

## Skills catalog

Choose a skill based on the task you want to complete. Each linked guide provides that skill's prerequisites and workflow. Start with the shared installation guide if you haven't set up the toolkit.

| Skill identifier | Customer task | Guide |
| --- | --- | --- |
| **`eeid-onboarding`** | Select an authentication approach and onboard an app to Microsoft Entra External ID. | [Onboard an app with the toolkit](how-to-ai-agent-toolkit-onboard). |
| **`eeid-native-auth-migrate-v2`** | Migrate an existing app from native authentication V1 to V2. | [Migrate native authentication with the toolkit](how-to-ai-agent-toolkit-migrate-native-auth-v2). |
