# Agent identity | Microsoft Learn

Microsoft Entra Agent ID extends identity and access management to AI agents, helping organizations secure access to applications, data, and services. Local agents on Windows act on behalf of the human user, with the agent’s identity included in requests to Microsoft Entra to distinguish agent activity from actions performed directly by the user. Organizations can use Microsoft Entra Agent ID with Conditional Access to apply policy-based controls to agent access to organizational resources. Centralized identity lifecycle management, sign-in logs, and audit logs help organizations maintain visibility and control as they adopt AI-powered workflows.
