# What's new in Windows security | Microsoft Learn

Windows is built on Zero Trust principles, with security from chip to cloud that helps you start secure, stay secure, protect your apps and data, and adopt AI safely. This article highlights new and expanded Windows security capabilities, listed by month with the most recent first.

For detailed release notes, see [Windows 11 release information](/en-us/windows/release-health/windows11-release-information).
