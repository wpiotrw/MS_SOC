How these numbers are counted

Added, removed and changed count every row of the table below them, both catalogs and the tracked components included. Endpoints and Message Center are counted apart: endpoints are not items, and Message Center is a VIEW over entries that are already counted in their own tab. A tile that is a link leads to where its own number is visible as the same number — the three totals to the table that decomposes them, every other tile to the section whose count it carries. Every tile is a link: a zero opens its section, which says what was compared and that nothing moved, and a tile stating a catalog size opens the section where that catalog is compared. Pressing one opens that section and closes the rest: every section starts collapsed, with its count in the chip beside its name. Message Center moved on its own this run: +10 / −5 / 5 revised. None of that is in the three totals above, and that is deliberate: an entry an item on this page cites is already counted in that item’s own tab (§3a, one home per item). 13 of these came from the index alone, so they have no item tab to be counted in and live only in the Message Center section. Left the window, not removed (§5bg): 90 community articles, 2 source pages, 33 blog articles and 46 Learn “what’s new” entries are no longer in the 14-day window or in their source’s feed. Nobody deleted them, so they are not in the totals.
